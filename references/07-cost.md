# 07 成本与取舍

## 记录实际成本

| 项目 | 记录方式 |
| --- | --- |
| Agent / 模型 | 使用的服务、调用或订阅分摊方式；拿不到用量时注明未知 |
| AIGC 素材 | 实际提交次数、模型、分辨率、成功与失败消耗 |
| 转写 | 实际计费单位、音频长度和账单 |
| 渲染与存储 | 本地或云端资源、存储及传输支出（如果发生） |
| 软件许可 | 按适用条款和购买记录，不把所有工具视为永久免费 |

具体金额以自己的账单、当前官方计费和本次用量为准；没有记录就不填估算数字冒充实际支出。不要将账号、账单个人信息或密钥放进公开文档。

## 时间成本

- 分别记录素材核验、转写、口播剪辑、包装、渲染、等待审核和修改所用时间。
- 模型、素材时长、设备、网络及修改范围都会影响耗时，不承诺固定一小时出片，也不按模型价格推断速度。
- 用一次小样的实际结果比较质量、返工量、等待时间和费用，再选适合项目的方案。

## 减少不必要的返工

- 默认先确认纯口播，再制作复杂画面；已批准的节奏不要无故重做。
- 能用真实素材或解释类 MG 表达的，不重复付费生成。
- 修改已获批准的局部时，复核该段、相邻接点及受影响图层；没有新问题时不把全片重新设计一遍。
- 记录素材、已确认规范和真实输出，避免误用旧版本或为同一素材多次下载。
- MG 工具分别核对许可证与渲染成本。开源或源码可见不等于所有使用场景无费用。

用户决定内容取舍与交付标准，Agent 用真实记录帮助控制预算。
