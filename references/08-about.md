# 08 关于这份工作流

这是一套供 Agent 读取的通用口播剪辑流程。它不附带作者原片、客户素材、字体或音乐资产，也不附带 API 账号和自动安装程序。

## 公开包的内容边界

- 使用通用目录模板，不包含作者电脑 / NAS 路径、真实账号、私有审阅链接或凭证。
- 字号、倍率、目录与镜头节奏是可调整的起点，用户当前要求与已确认规范优先。
- 工具能力、模型、许可和计费随版本变化，接入时以官方文档和最小实测为准。
- 依靠外部服务的操作，需要可用工具与本次授权；阅读本包不代表这些服务已经连接。

## 验证范围

本发布候选已做 Markdown/YAML 结构检查、相对链接检查、源文件与 ZIP 一致性检查，以及文档中 ffprobe / 场景变化检测命令的合成样本测试。测试使用已安装工具，不含真实用户素材。

这不等于全流程测试：没有用本包在每种客户端安装，也没有由本包完成所有剪辑、转写、付费生成、上传审阅和归档服务的端到端验证。接入者需要在自己的环境确认相应能力。

## 版本

- v1：七个环节的初版文档。
- v1.1：公开候选审核；修正切点日志命令，区分时间戳单位与识别精度，移除普遍性能/价格承诺，将审批、音效、目录和归档改为按当前授权与内容需要执行。

用户要求更新时，可将反复出现的要求写回自己的 Skill；个人偏好不要未经说明变成公共默认。
