# 03 口播精剪（A-Roll）

口播决定整条片子的章节、时长和节奏，所以**第一步永远是把它剪顺**。

## 流程

1. **语音转文字**
   - 优先使用能返回词级时间戳的转写服务，例：豆包语音识别；也可用剪辑软件内置转写。先确认当前模型实际返回到词还是到句。
   - 输出：带时间戳的词表，Agent 后面所有剪切都基于它。
   - 毫秒是时间戳单位，不等于识别误差只有 1 毫秒。剪口还须结合真实波形、前后文与听感，不截断声母、韵母或自然气口。
2. **把声音问题变成代码问题**
   - 转写完成后，删除重复、卡壳、口误、无意义停顿，就是一份可审查的「剪切清单」。
   - 留下可审查的剪切清单；已有剪辑授权时可直接执行并交纯口播版，语义取舍不确定再确认。
3. **调整语速**
   - 常见做法是统一到 1.2 倍左右并保留音高（不要变成花栗鼠）；具体倍率按你的说话习惯定，定了就写进 Skill 当默认。
   - 顺序：先清理口误与停顿，再统一变速；已经达到目标倍率的片段不要重复乘速。
4. **先出纯口播版给你确认**
   - 默认先确认口播节奏，避免复杂包装后大改；用户已批准或明确授权自主继续时，不重复请求同一确认。
   - 你确认节奏 OK，再往下做画面。

## 常见坑

- **时间码要对版本**：你给的时间码是上一版的，新版时长变了以后必须做版本映射，不能直接套。
- **字幕不是听写**：专有名词、数字、人名要人工复核。AI 转写会把「8 个版本」听成「8 百版本」这种事。
- **画面和声音共用一套剪切映射**：变速了，画面也要同样变速，否则口型和手指动作对不上。
- **按听感衔接**：可以细剪词句，但要连听前后片段，保留必要气口，避免尾音截断、重叠或呼吸不自然。

## 交付这一环节时给出

- 纯口播版视频（或音频）+ 剪切清单（删了什么、为什么）。
- 口播最终时长与倍率记录，方便后面所有画面按同一时间线对齐。
