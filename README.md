# AI 剪辑工作流（通用版 v1.1）

用于把口播类视频的后期任务交给能读写文件、调用剪辑工具的 AI Agent：软件准备 → 素材整理 → 口播精剪 → B-Roll 分镜 → 包装音效 → 审阅交付 → 成本记录。

这是流程 Skill，不是一键剪辑程序，也不附带软件、账号、模型额度或用户素材。

## 开始使用

1. 下载并解压完整包，确认 `ai-video-editing-workflow/SKILL.md` 和 `references/` 在同一层。不要只下载主文件。
2. 把该文件夹交给能读取本地文件的 Agent，或将整个文件夹放进客户端官方文档指定的 skills 目录。不同客户端的自动发现路径不同。
3. 给出项目位置和任务，例如：「读取这份 Skill。素材在【项目路径】，脚本在【脚本路径】；先整理素材、剪出纯口播版给我确认，再继续包装。」
4. Agent 先检查软件、文件访问与实际工具能力。已有软件和授权能用就继续；缺少外部服务时明确缺哪一项，不把阅读文档说成已接通工具。

不支持安装 Skill 的客户端也可将它作为完整工作流文档读取。首次应确认 Agent 能引用主文件和所需细则；本包没有安装脚本，不会自动修改配置。

## 需要准备

- 口播原片、脚本与项目目录；已有风格参考可一并提供。
- 可用的剪辑工具（例如有 MCP / CLI 的编辑器），以及完成任务所需的转写能力。
- 只有要生成素材或在线审阅时，才需要对应的服务和授权。不要把账号密码或 API 密钥写进本包。

默认先确认纯口播节奏，再做复杂包装；其他确认点按本次授权和修改风险安排，不要求每一步都停下来。已有批准可以继续沿用。
